# Security policy

## Supported versions

Only the latest published release is supported. Please reproduce an issue with
that release before reporting it.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/jakobmart4/Scannx-Tools/security/advisories/new)
for a script that changes the system unexpectedly, sends data out unexpectedly,
or executes something it should not. Include the affected version, a minimal
reproduction, expected and actual behavior, and the security impact.

Do not attach real reports or logs without removing personal data, paths and
credentials. If private reporting is unavailable, open an issue asking the
maintainer to enable it, without publishing vulnerability details.

A missed detection or an inaccurate diagnostic verdict belongs in an ordinary
issue, with synthetic examples. Scannx is a diagnostic tool, not an antivirus.
